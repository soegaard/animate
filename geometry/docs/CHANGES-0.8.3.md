# Changes in v0.8.3

- Distinctly scalene acute triangles in the circumcenter, incircle, orthocenter,
  SAS-copy and triangle-midline examples.
- Left-side angle copying in the standalone example, matching its source angle.
- Closer, fixed point-relative labels for P₁...P₅; new `label-offset` layout hint.
- H's label moved clear of the revised orthocenter's altitude strokes.
- P/Q/R/S-style standard helper names instead of X/Y; structured captions updated.
- Purple primary circumcircle and aqua auxiliary circles in the hexagon example.
- Lines/rays rendered behind finite objects, preserving the square's gold AB.
- Helper annotation hints correctly remapped onto caller-visible result aliases.
- New headless/native regression cases; `run-tests.rkt --refinements`.
- Both manual copies, construction reference, source/testing notes updated.

The static-frame renderer and its import/syntax fixes, process workers, review
bundles, reading delay, marker sizes and light/dark modes are retained. See
[the example notes](EXAMPLE-REFINEMENTS.md) for validation boundaries and details.
